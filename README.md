# Rainfall Analysis Dashboard (India 1901–2015)

This Tableau project analyzes historical rainfall patterns across Indian states using rainfall data from 1901 to 2015. The dashboard provides interactive visualizations to explore yearly rainfall trends, state-wise rainfall distribution, seasonal rainfall reports, and the top rainfall-receiving states.

### Key Features

* Yearly rainfall trend analysis
* State-wise rainfall map visualization
* Seasonal rainfall comparison by state
* Top 10 states by rainfall
* Interactive Tableau dashboard for data exploration

### Tools Used

* Tableau
* Excel/CSV Dataset
* Data Visualization

### Insights Generated

* Long-term rainfall trends across India
* Regional differences in rainfall distribution
* Seasonal rainfall patterns
* Identification of high and low rainfall states

This project demonstrates data visualization, dashboard design, and analytical storytelling using Tableau.
